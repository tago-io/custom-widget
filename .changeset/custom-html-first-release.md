First release of the Custom HTML SDK. `@tago-io/custom-html` is a promise client for the Custom HTML `postMessage` bridge that runs saved TagoSQL queries and reads the host's theme, style and link params; `@tago-io/custom-html-react` adds a React provider and hooks on top of it.
